# ما بعد الضيق الا الفرج.

حكاية عربية تفاعلية من العتمة إلى الفجر، بلوحات مرسومة يتغيّر ضوؤها مع القراءة وقرار الزائر.

افتح index.html للمعاينة. الموقع محلي ولم يُنشر.

المحتوى حكاية أدبية، وجميع المشاهد رسوم رمزية وليست صوراً أو أدلة توثيقية.
التفاعلات محلية، ولا تُجمع الاختيارات أو تُحفظ بعد إعادة تحميل الصفحة.
استُخدم خط IBM Plex Sans Arabic المحلي بدلاً من خطوط المرجع غير المرفقة.

الخط IBM Plex Sans Arabic بترخيص SIL OFL، والترخيص في fonts/.
